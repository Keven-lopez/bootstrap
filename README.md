# Bootstrap Portafolio Personal

Este proyecto tiene como objetivo crear un portafolio personal utilizando HTML5, CSS3 y Bootstrap, donde se presentan mis habilidades, intereses, proyectos y medios de contacto mediante un diseño moderno y responsive.

Para ejecutar la página solamente es necesario abrir el archivo `index.html` en un navegador web. Bootstrap fue utilizado mediante CDN, por lo que no requiere configuraciones adicionales.

Durante el desarrollo se utilizaron componentes de Bootstrap como Navbar, Container, Grid System, Cards, List Groups y Buttons. Además, se personalizó el diseño mediante CSS utilizando variables de color, fuentes personalizadas, estilos propios para botones, tarjetas y secciones, adaptando la apariencia a un tema oscuro con detalles en color dorado.

Las principales decisiones de diseño fueron enfocarse en una estructura limpia y fácil de navegar, utilizando un diseño responsive que se adapte a diferentes tamaños de pantalla y una distribución organizada de la información para mejorar la experiencia del usuario.
